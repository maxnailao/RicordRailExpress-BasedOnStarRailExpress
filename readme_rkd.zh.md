## 项目来源声明

本项目（RicordRailExpress）是基于**残月团队**拓展开发的 **StarRail Express** 模组，由**瑞科德列车制作组**在其基础上进行的二次修改版本。

本项目所使用的源码来源于残月团队公开发布的 StarRail Express 开源代码。我们在其基础上进行了进一步的开发、修改与优化，以适应瑞科德列车制作组的需求与设计理念。

## 致谢

我们在此向**残月团队**表达诚挚的感谢。感谢残月团队将 StarRail Express 以开源形式发布，使得我们能够在其优秀的工作成果之上进行二次创作与改进。没有残月团队的开源精神与辛勤付出，本项目将无从谈起。
