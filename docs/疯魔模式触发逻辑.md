# 疯魔模式（Psycho Mode）触发逻辑参考文档

本文档整理了普通球棒疯魔模式的完整触发逻辑，供创建新角色/新疯魔变体时参考。

---

| 组件 | 文件路径 | 作用 |

| `SREPlayerPsychoComponent` | `/src/main/java/io/wifi/starrailexpress/cca/SREPlayerPsychoComponent.java` | 管理疯魔状态、时间、护盾 |

## 3. 完整触发流程

### 3.1 商店购买入口

**文件**: `ShopContent.java`

```java
// 创建商店条目
defaultKnifeEntries.add(new ShopEntry(
    TMMItems.PSYCHO_MODE.getDefaultInstance(),
    SREConfig.instance().psychoModePrice,  // 400金币
    ShopEntry.Type.WEAPON
) {
    @Override
    public boolean canBuy(@NotNull Player player) {
        // 检查个人冷却
        if (player.getCooldowns().isOnCooldown(TMMItems.PSYCHO_MODE)) {
            return false;
        }
        return super.canBuy(player);
    }

    @Override
    public boolean onBuy(@NotNull Player player) {
        // 二次检查冷却
        if (player.getCooldowns().isOnCooldown(TMMItems.PSYCHO_MODE)) {
            return false;
        }
        
        // 给全服玩家添加全局冷却（防止连续购买）
        player.level().players().forEach(player1 -> {
            if (!player1.getCooldowns().isOnCooldown(TMMItems.PSYCHO_MODE)) {
                player1.getCooldowns().addCooldown(
                    TMMItems.PSYCHO_MODE,
                    SREConfig.instance().psychoGlobalCooldown  // 20秒
                );
            }
        });
        
        // 触发疯魔模式
        return SREPlayerShopComponent.usePsychoMode(player);
    }
});
```

### 3.2 商店组件调用

**文件**: `SREPlayerShopComponent.java`

```java
public static boolean usePsychoMode(@NotNull Player player) {
    return usePsychoMode(player, 1d);  // 默认1倍时间
}

public static boolean usePsychoMode(@NotNull Player player, double multtiplier) {
    return usePsychoMode(player, multtiplier, 1);  // 默认1层护盾
}

public static boolean usePsychoMode(@NotNull Player player, double multtiplier, int armour) {
    // 1. 添加个人冷却
    player.getCooldowns().addCooldown(
        TMMItems.PSYCHO_MODE,
        GameConstants.ITEM_COOLDOWNS.getOrDefault(TMMItems.PSYCHO_MODE, 0)  // 275秒
    );
    
    // 2. 启动疯魔组件
    boolean started = SREPlayerPsychoComponent.KEY.get(player).startPsycho(multtiplier, armour);
    
    // 3. 记录技能使用（回放系统）
    if (started) {
        SRE.REPLAY_MANAGER.recordSkillUsed(
            player.getUUID(), 
            BuiltInRegistries.ITEM.getKey(TMMItems.PSYCHO_MODE)
        );
    }
    
    return started;
}
```

### 3.3 疯魔组件启动

**文件**: `SREPlayerPsychoComponent.java`

```java
public boolean startPsycho(double multtiplier, int armour) {
    // 计算实际持续时间（毫秒转tick）
    int time = (int) ((double) GameConstants.getPsychoTimer() * multtiplier);
    return startPsycho_time(time, armour);
}

public boolean startPsycho_time(int time, int armour) {
    // 1. 检查是否已在疯魔状态
    if (this.psychoTicks > 0)
        return false;
    
    // 2. 获取玩家角色
    SRERole role = SRERoleWorldComponent.KEY.get(this.player.level()).getRole(this.player);
    boolean success = false;
    
    // 3. 给予疯魔武器（角色可自定义）
    if (role != null) {
        success = role.onPsychoGiveItem(player, this);
    } else {
        // 默认给球棒
        success = RoleUtils.insertStackInFreeSlot(player, new ItemStack(TMMItems.BAT));
    }
    
    // 4. 武器给予成功后设置状态
    if (success) {
        this.setPsychoTicks(time);           // 设置持续时间
        this.setArmour(armour);              // 设置护盾层数
        
        // 5. 增加全局疯魔计数
        SREGameWorldComponent gameWorldComponent = SREGameWorldComponent.KEY.get(this.player.level());
        gameWorldComponent.setPsychosActive(gameWorldComponent.getPsychosActive() + 1);
        
        // 6. 触发客户端状态栏
        if (player instanceof ServerPlayer serverPlayer) {
            ServerPlayNetworking.send(serverPlayer, new TriggerStatusBarPayload("Psycho"));
        }
        
        // 7. 调用角色回调
        if (role != null) {
            role.onPsychoStart(player, this);
        }
        
        return true;
    }
    
    return false;
}
```

## 4. 运行期间逻辑

### 4.1 服务端Tick（每tick执行）

**文件**: `SREPlayerPsychoComponent.java`

```java
@Override
public void serverTick() {
    // 1. 检查游戏是否运行中
    if (!checkIsGameRunning()) {
        if (this.psychoTicks > 0) {
            this.stopPsycho();  // 游戏结束则停止疯魔
        }
        return;
    }
    
    // 2. 未激活则跳过
    if (this.psychoTicks <= 0)
        return;
    
    // 3. 玩家死亡/旁观则强制停止
    if (this.psychoTicks > 0) {
        if (this.player.isSpectator()) {
            this.stopPsychoAndRefreshPsychoCount(true);
            return;
        }
    }
    
    // 4. 倒计时
    if (--this.psychoTicks == 0) {
        this.stopPsycho();  // 时间到，结束疯魔
        this.sync();
    } else {
        // 5. 每10秒同步一次状态
        if (this.psychoTicks % 200 == 0) {
            this.sync();
        }
    }
}
```

### 4.2 客户端Tick（自动切武器）

**文件**: `SREPlayerPsychoComponent.java`

```java
@Override
public void clientTick() {
    if (!checkIsGameRunning()) {
        if (this.psychoTicks > 0)
            this.psychoTicks = -1;
        return;
    }

    if (this.psychoTicks <= 0)
        return;
    
    if (this.psychoTicks > 1) {
        if (this.player.isSpectator()) {
            this.psychoTicks = -1;
            return;
        }
        this.psychoTicks--;
    }
    
    // 获取疯魔武器类型（默认球棒）
    Item psychoItem = TMMItems.BAT;
    SRERole role = SRERoleWorldComponent.KEY.get(this.player.level()).getRole(player);
    if (role != null) {
        psychoItem = role.getPsychoItem();
    }
    
    // 如果已持有则跳过
    if (this.player.getMainHandItem().is(psychoItem))
        return;
    
    // 自动切换到包含疯魔武器的快捷栏槽位
    if (GameUtils.isPlayerAliveAndSurvivalIgnoreShitSplit(player)) {
        for (int i = 0; i < 9; i++) {
            if (!this.player.getInventory().getItem(i).is(psychoItem))
                continue;
            this.player.getInventory().selected = i;
            break;
        }
    }
}
```

## 5. 护盾抵挡机制

### 5.1 伤害判定流程

**文件**: `GameMode.java`

```java
// 检查疯魔护盾（在通用护盾之后）
if (psychocca.getPsychoTicks() > 0) {
    if (!forceDeath && psychocca.getArmour() > 0) {
        // 1. 减少护盾
        psychocca.setArmour(psychocca.getArmour() - 1);
        
        // 2. 记录回放
        if (SRE.REPLAY_MANAGER != null) {
            SRE.REPLAY_MANAGER.breakArmor(victim.getUUID());
        }

        // 3. 显示消息
        victim.displayClientMessage(
            Component.translatable("message.bartender.armor_broke_self")
                .withStyle(ChatFormatting.YELLOW), 
            true
        );
        
        // 4. 记录未击杀
        SRE.REPLAY_MANAGER.recordPlayerNotKilled(killer, victim, deathReason);
        
        // 5. 发送破盾粒子给攻击者
        if (killer instanceof ServerPlayer serverPlayer) {
            ServerPlayNetworking.send(
                serverPlayer,
                new BreakArmorPayload(victim.getX(), victim.getY(), victim.getZ())
            );
        }
        
        // 6. 同步状态
        psychocca.sync();
        
        // 7. 播放破盾音效
        victim.playNotifySound(TMMSounds.ITEM_PSYCHO_ARMOUR, SoundSource.MASTER, 5F, 1F);
        
        // 8. 阻止死亡（非强制死亡时）
        if (!forceDeath)
            return;
    } else {
        // 护盾为0，结束疯魔模式
        psychocca.stopPsycho();
        psychocca.sync();
    }
}
```

**关键点**:
- 疯魔护盾在 `SREArmorPlayerComponent` 通用护盾之后检查
- 每次受击减少1层护盾
- 护盾为0时自动结束疯魔模式
- 强制死亡（`forceDeath=true`）会无视护盾

## 6. 结束逻辑

### 6.1 正常结束

**文件**: `SREPlayerPsychoComponent.java`

```java
public int stopPsycho() {
    // 1. 减少全局疯魔计数
    SREGameWorldComponent gameWorldComponent = SREGameWorldComponent.KEY.get(this.player.level());
    int result = gameWorldComponent.getPsychosActive();
    if (result >= 1) {
        gameWorldComponent.setPsychosActive(result - 1);
    }
    
    // 2. 重置时间
    this.psychoTicks = -1;
    
    // 3. 移除状态栏
    if (this.player instanceof ServerPlayer serverPlayer) {
        ServerPlayNetworking.send(serverPlayer, new RemoveStatusBarPayload("Psycho"));
    }

    // 4. 清理疯魔武器
    Item psychoItem = TMMItems.BAT;
    SRERole role = SRERoleWorldComponent.KEY.get(this.player.level()).getRole(player);
    if (role != null) {
        psychoItem = role.getPsychoItem();
    }
    MCItemsUtils.clearItem(player, psychoItem);
    
    // 5. 调用角色结束回调
    if (checkIsGameRunning()) {
        if (GameUtils.isPlayerAliveAndSurvival(player)) {
            if (role != null) {
                role.onPsychoOver(player, this);
            }
        }
    }
    
    return result;
}
```

@Inject(method = "usePsychoMode(Lnet/minecraft/world/entity/player/Player;DI)Z",

    @NotNull Player player,

        psychoComponent.setPsychoTicks(20 * 22);

public boolean startFrenzy() {
    SREPlayerPsychoComponent psychoComponent = SREPlayerPsychoComponent.KEY.get(player);

    }

    }

    this.inFrenzy = true;
    return true;

## 12. 常见问题

**Q: 为什么 `startPsycho()` 返回 false？**  
A: 可能原因：
1. 玩家已在疯魔状态（`psychoTicks > 0`）
2. 背包已满，无法给予武器
3. 游戏未运行

**Q: 护盾为0时会自动结束吗？**  
A: 会。当护盾为0且再次受击时，会调用 `stopPsycho()` 结束疯魔模式。

**Q: 如何强制结束疯魔？**  
A: 调用 `stopPsychoAndRefreshPsychoCount(true)`，会同步全局计数。

**Q: 全局冷却和个人冷却的区别？**  
A: 全局冷却影响所有玩家（防止连续购买），个人冷却只影响购买者。
