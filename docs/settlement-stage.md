# 结算舞台

结束对局后，服务端在清除职业和击杀数据前冻结胜负、MVP 与回放事件。客户端先显示黑幕，待专用舞台及区块准备完毕后播放谢幕、MVP 展示和 MVP 相关事件；玩家长按 Enter 可跳过。跳过需要开场满 100 tick，并持续按住 30 tick。

## 配置

配置位于 `config/starrailexpress.json`。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `enableSettlementStage` | `true` | 是否播放结算舞台 |
| `settlementStageX` | `-100000` | 舞台原点 X |
| `settlementStageY` | `0` | 舞台原点 Y |
| `settlementStageZ` | `0` | 舞台原点 Z |

舞台会重建原点附近 X/Z 约 33×31 格、高 15 格的区域，应使用专用空地。坐标必须位于世界边界和建筑高度内，且不能与大厅、游戏区或地图模板区域重叠；不满足时跳过演出。

## 胜负、统计与恢复

MVP 只从获胜者中选择，贡献分为击杀数加非杀手的任务完成数；同分依次比较击杀数和 UUID。胜负沿用本地职业判定，包括跟随胜利与职业事件覆盖。计入战绩的模式同时记录总 MVP 次数与对应职业 MVP 次数。舞台关闭时仍可记录 MVP。

结算音乐优先使用本局 MVP 装备的音乐盒，没有则按本地玩家胜负播放默认钢琴音。舞台期间屏蔽现场声音和语音。

演出结束、跳过、超时、断线或服务器停止时恢复玩家的原模式和大厅位置。开始新局、地图投票或通用投票会先结束舞台。参演玩家在舞台期间仍计入准备人数。

## 扩展

结算皮肤使用 `ItemSkinManager.SkinTypes.MVP_ANIMATION` 槽位，由服务端按 MVP 实际解锁和装备的记录选择。客户端通过 `SettlementSkins.register` 注册表现，服务端通过 `SettlementTerrains.register` 注册舞台地形。默认皮肤 ID 为 `default`；本体不内置特定主题皮肤。
