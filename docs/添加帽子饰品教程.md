# 添加帽子饰品教程

把一个 Blockbench 帽子模型 + 贴图做成游戏里的「帽子饰品」，可选塞进帽子饰品箱。

帽子饰品本质上是 CS2 仓库里的 `hat/*` 皮肤：皮肤 ID 形如 `hat/hat_<名字>`。拥有后可以在仓库里左键/右键装备到头上。瑞科德饰品（钢盔/耳机这类）除了是仓库皮肤，还要额外注册成一个**物品**，出现在创造物品栏的「瑞科德饰品」标签页里。

---

## 一、目录约定

每个帽子（假设帽子名是 `my_hat`，物品 id 是 `ricord_my_hat`）涉及这些文件：

| 类型 | 路径 |
|------|------|
| 帽子模型 | `src/main/resources/assets/starrailexpress/models/item/skins/hat/hat_my_hat.json` |
| 贴图 | `src/main/resources/assets/starrailexpress/textures/item/skins/hat/hat_my_hat*.png` |
| 物品模型 | `src/main/resources/assets/noellesroles/models/item/ricord_my_hat.json` |
| 物品注册 | `src/main/java/org/agmas/noellesroles/init/ModItems.java` |
| 皮肤注册 | `src/main/java/io/wifi/starrailexpress/index/SRESkinRegistry.java` |
| 皮肤中文名 | `src/main/java/org/agmas/noellesroles/cs2/CS2SkinInfo.java` |
| 语言文件 | `src/main/resources/assets/noellesroles/lang/zh_cn.json` |
| 帽子箱子 | `CS2_box/hat_box.json`（同时 `run/CS2_box/hat_box.json` 一份） |

> 渲染链路：装备帽子后，`HatSkinRenderer` 优先读 `models/item/skins/hat/hat_<名字>.json` 这个模型。模型里带 `display.head` 的（瑞科德饰品）走原版头顶物品管线，作者在 Blockbench「Display → Head」里调好的朝向/位置/缩放会原样生效；继承玩偶方块模型的玩偶帽走玩偶缩放链路。

---

## 二、品级（品质）说明

皮肤有 6 个品级，决定仓库/开箱里的边框颜色和掉落概率。品级 ↔ 箱子列表字段 ↔ 颜色：

| 品级（中文） | QualityColor 枚举 | 箱子字段 | 帽子箱概率 |
|--------------|-------------------|----------|-----------|
| 普通 | `COMMON` | `common_skins` | 79.92% |
| 罕见 | `UNCOMMON` | `uncommon_skins` | 15.98% |
| 稀有 | `RARE` | `rare_skins` | 3.2% |
| 史诗 | `EPIC` | `epic_skins` | 0.64% |
| 传说 | `LEGENDARY` | `legendary_skins` | 0.26% |
| 不可思议 | `UNBELIEVABLE` | `unbelievable_skins` | 0% |

皮肤品级在 `SRESkinRegistry` 里注册（`registerSkin(..., QualityColor.XXX)`），塞箱子时再按品级把皮肤 ID 放进对应的 `*_skins` 列表。

---

## 三、完整流程（以「小猫耳机」为例）

### 第 1 步：准备模型和贴图

- 用 Blockbench 建好帽子模型，导出成**基岩版 JSON**（带 `format_version`、`textures` 是 dict、`faces` 里是 `#0` 这种占位）。
- 把导出的 JSON 和贴图 PNG 都放进 `docs/`。

例子：

```
docs/小猫耳机.json     # 基岩版模型
docs/白.png   docs/黑.png   docs/粉色.png   # 三张贴图
```

> 贴图数量：模型用了几个纹理（`textures` 里有 `"0"/"1"/"2"...`），就准备几张 PNG。贴图尺寸跟模型分辨率一致（一般是 16×16 或 32×32）。

### 第 2 步：转换模型（基岩版 → Java 物品模型）

改 `build/hat_convert.py` 顶部的配置，然后运行：

```python
SRC = os.path.join(ROOT, "docs", "小猫耳机.json")            # 输入
SKIN_NAME = "hat_ricord_cat_headset"                          # 输出皮肤名

TEX_MAP = {
    "0": "starrailexpress:item/skins/hat/" + SKIN_NAME,               # 白
    "1": "starrailexpress:item/skins/hat/" + SKIN_NAME + "_black",    # 黑
    "2": "starrailexpress:item/skins/hat/" + SKIN_NAME + "_pink",     # 粉
    "particle": "starrailexpress:item/skins/hat/" + SKIN_NAME,
}

TEX_COPY = {
    "0": os.path.join(ROOT, "docs", "白.png"),
    "1": os.path.join(ROOT, "docs", "黑.png"),
    "2": os.path.join(ROOT, "docs", "粉色.png"),
}
```

```bash
python build/hat_convert.py
```

脚本会：
- 把纹理命名空间改对（`#0` 等占位 → `starrailexpress:item/skins/hat/hat_<名字>`）；
- 处理旋转（Java 只允许 -45/-22.5/0/22.5/45°，其它角度会被烘焙进 `from/to` 坐标）；
- 复制真实贴图到 `textures/item/skins/hat/`（没在 `TEX_COPY` 里提供的才生成纯色占位贴图）；
- 保留模型自带的 `display`（含 `head` 变换）。

### 第 3 步：注册皮肤（带品级）

在 `SRESkinRegistry.java` 的帽子区加一行，第三参是品级：

```java
registerSkin(SkinTypes.HAT, "hat_ricord_cat_headset", QualityColor.LEGENDARY);
```

### 第 4 步：注册皮肤中文名和描述

在 `CS2SkinInfo.java` 的帽子区加一行：

```java
register("hat/hat_ricord_cat_headset", "小猫耳机", "瑞科德饰品：猫耳头戴式耳机，戴上后猫耳会立在头上");
```

### 第 5 步：注册物品 + 物品模型 + 语言文件

**① 注册物品**（`ModItems.java`，传 `RICORD_ACCESSORIES_GROUP` 就会进「瑞科德饰品」标签页）：

```java
public static final Item RICORD_CAT_HEADSET = register(
        new Item(new Item.Properties().stacksTo(1)),
        "ricord_cat_headset", RICORD_ACCESSORIES_GROUP);
```

**② 建物品模型**（`models/item/ricord_cat_headset.json`），`parent` 指向 3D 帽子模型，这样创造栏图标显示的是 3D 耳机而不是平贴图：

```json
{
    "parent": "starrailexpress:item/skins/hat/hat_ricord_cat_headset",
    "display": {
        "gui": { "rotation": [30, 45, -60], "translation": [0, 0, 0], "scale": [0.55, 0.55, 0.55] },
        "ground": { "rotation": [0, 0, 0], "translation": [0, 3, 0], "scale": [0.5, 0.5, 0.5] },
        "thirdperson_righthand": { "rotation": [0, 0, 0], "translation": [0, 1, 1], "scale": [0.4, 0.4, 0.4] }
    }
}
```

**③ 加语言条目**（`lang/zh_cn.json`）：

```json
"item.noellesroles.ricord_cat_headset": "小猫耳机",
```

### 第 6 步（可选）：按品级塞进帽子箱子

在 `CS2_box/hat_box.json` **和** `run/CS2_box/hat_box.json` 里，把皮肤 ID 加进对应品级的列表。比如放进「普通」：

```json
"common_skins": [
  "hat/hat_ricord_green_camo",
  "hat/hat_ricord_cat_headset"
]
```

- 皮肤 ID 是 `hat/hat_<名字>`（注意带 `hat/` 前缀）。
- 放哪个列表就对应哪个品级（见第二节表格）。两处 `hat_box.json` 都要改，保持一致。

## 四、快速检查清单

- [ ] `docs/` 里有模型 JSON 和贴图 PNG

- [ ] `SRESkinRegistry` 注册了 `hat_<名字>`（带品级）
- [ ] `CS2SkinInfo` 注册了 `hat/hat_<名字>` 中文名

- [ ] `models/item/<物品id>.json` 物品模型存在
- [ ] `lang/zh_cn.json` 有 `item.noellesroles.<物品id>` 条目
- [ ] （可选）`CS2_box/hat_box.json` 和 `run/CS2_box/hat_box.json` 按品级加了皮肤 ID
- [ ] `./gradlew compileJava` 编译通过

## 五、关于箱子 / 商店 / 重复返还

- 箱子配置：`CS2_box/<boxId>.json`（同时 `run/CS2_box/` 一份），字段 `box_name`、`key_name`、各品级概率和皮肤列表。
- 黑市商店：`run/config/shopprice.json` 的 `shopprice` 里加 `{name, type(box/key), id, price}`。
- **重复返还已内置**：开箱开到已经拥有的 `hat/*` 帽子时，会自动返还 100 货币（逻辑在 `CS2BoxManager.rollAndGrant`）。

## 六、新增一种「皮肤分类」（仓库侧边栏）

仓库皮肤按 `skinId` 前缀（`类型/名字`）自动归类。现在有这 5 类：`knife`(刀) / `revolver`+`gun`(左轮手枪) / `bat`(棒球棍) / `grenade`(手雷) / `hat`(帽子)。

要新增一个类型（比如 `xxx`），改 `src/main/java/org/agmas/noellesroles/client/screen/CS2WarehouseScreen.java` 里 4 处：

1. **枚举**加一项：
   ```java
   private enum Category { ALL, BOXES, KNIFE, REVOLVER, BAT, GRENADE, HAT, XXX, MUSIC, CARDS }
   ```

2. **`isSkinCategory`** 加上这个枚举值：
   ```java
   return c == Category.ALL || ... || c == Category.HAT || c == Category.XXX;
   ```

3. **`skinCategoryMatches`** 加一条映射：
   ```java
   case XXX -> "xxx".equals(itemType);
   ```

4. **两个侧边栏数组**（`renderSidebar` 和 `mouseClicked` 里各一处）补上分类和中文名：
   ```java
   Category[] categories = { ..., Category.HAT, Category.XXX, Category.MUSIC, Category.CARDS };
   String[] labels = { ..., "帽子", "XXX中文名", "音乐盒", "职业卡" };
   ```

> 注意：`skinId` 里 `类型` 那一段要和 `skinCategoryMatches` 里的字符串完全一致（区分大小写）。皮肤本身不用改，前缀对上了就会自动归到新分类。

## 七、把瑞科德饰品加进创造物品栏标签页

瑞科德饰品（帽子/钢盔/耳机）除了是 CS2 仓库皮肤，还要注册成一个**物品**，才能出现在创造物品栏的「瑞科德饰品」标签页里。

1. 在 `ModItems.java` 里注册物品，并把 `RICORD_ACCESSORIES_GROUP` 传进去（见第三节第 5 步）。

2. 给这个物品建一个物品模型 `models/item/<物品id>.json`，用 `parent` 指向 3D 帽子模型（见第三节第 5 步）。

> 标签页「瑞科德饰品」本身已在 `TMMItems` 里注册好（`RICORD_ACCESSORIES_GROUP`），图标用的是第一个饰品物品（`RICORD_GREEN_CAMO_HELMET`）。以后新增饰品，物品直接传 `RICORD_ACCESSORIES_GROUP` 就会自动进这个标签页，不用再改标签页注册代码。
