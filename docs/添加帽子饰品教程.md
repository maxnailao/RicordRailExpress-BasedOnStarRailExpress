# 添加帽子饰品（瑞科德饰品）教程

帽子饰品本质上是 CS2 仓库里的 `hat/*` 皮肤：皮肤 ID 形如 `hat/hat_<名字>`，拥有后可以在仓库里左键/右键装备到头上。

## 一、目录约定

每个帽子需要两个文件（假设帽子名是 `my_hat`）：

| 类型 | 路径 |
|------|------|
| 模型 | `src/main/resources/assets/starrailexpress/models/item/skins/hat/hat_my_hat.json` |
| 贴图 | `src/main/resources/assets/starrailexpress/textures/item/skins/hat/hat_my_hat.png` |

> 渲染链路：装备帽子后，`HatSkinRenderer` 会优先读 `models/item/skins/hat/hat_<名字>.json` 这个模型（找不到才回退到同名 plush 方块）。

## 二、添加一个新帽子（四步）

### 第 1 步：注册皮肤中文名

在 `src/main/java/org/agmas/noellesroles/cs2/CS2SkinInfo.java` 的帽子区加一行：

```java
register("hat/hat_my_hat", "我的帽子", "把「我的帽子」戴在头上");
```

### 第 2 步：准备模型 + 贴图

- 把 Blockbench 模型 JSON 放到 `docs/`。
- 把贴图 PNG 也放进 `docs/`（**贴图尺寸要跟模型 `texture_size` 一致**，一般 32×32 或 64×64）。

### 第 3 步：转换模型（Bedrock → Java）

模型如果是 Blockbench 基岩版格式（带 `format_version`、`textures` 里是 `"0": "block/texture"` 这类占位），不能直接用，要用脚本转成 Java 物品模型。

仓库里已经有一个转换脚本 `build/hat_convert.py`，你只要改里面三个地方：

```python
SRC = os.path.join(ROOT, "docs", "你的模型.json")     # 输入
OUT_MODEL = ... "hat_my_hat.json"                       # 输出模型名
tex_map = {
    "0": "starrailexpress:item/skins/hat/hat_my_hat",   # 贴图命名空间
    "particle": "starrailexpress:item/skins/hat/hat_my_hat",
}
```

然后运行：

```bash
python build/hat_convert.py
```

脚本会：
- 把纹理命名空间改对；
- 处理旋转（Java 只允许 -45/-22.5/0/22.5/45°，其它角度比如 90° 会被**烘焙进 `from/to` 坐标**）；
- 生成占位贴图（纯色 PNG，之后替换成正式贴图即可）。

> 转换后记得把 `docs/` 里的正式贴图 PNG 覆盖到 `textures/item/skins/hat/hat_my_hat.png`。

### 第 4 步：加入箱子（可选）

在箱子配置 `CS2_box/hat_box.json`（以及 `run/CS2_box/hat_box.json`）里，把皮肤 ID 加进对应品质列表：

```json
"common_skins": [
  "hat/hat_ricord_green_camo",
  "hat/hat_my_hat"
]
```

品质字段：`common_skins` / `uncommon_skins` / `rare_skins` / `epic_skins` / `legendary_skins` / `unbelievable_skins`。

## 三、关于箱子 / 商店 / 重复返还

- 箱子配置：`CS2_box/<boxId>.json`（同时 `run/CS2_box/` 一份），字段 `box_name`、`key_name`、各品质概率和皮肤列表。
- 黑市商店：`run/config/shopprice.json` 的 `shopprice` 里加 `{name, type(box/key), id, price}`。
- **重复返还已内置**：开箱开到已经拥有的 `hat/*` 帽子时，会自动返还 100 货币（逻辑在 `CS2BoxManager.rollAndGrant`）。

## 四、快速检查清单

- [ ] `CS2SkinInfo` 注册了 `hat/hat_<名字>` 中文名
- [ ] `models/item/skins/hat/hat_<名字>.json` 存在且是 Java 模型（无 `format_version`、无 `block/texture`）
- [ ] `textures/item/skins/hat/hat_<名字>.png` 存在
- [ ] 箱子 `common_skins` 等列表里加了该皮肤 ID
- [ ] （可选）商店 `shopprice.json` 里加了箱子/钥匙

## 五、新增一种「皮肤分类」（仓库侧边栏）

仓库皮肤按 `skinId` 前缀（`类型/名字`）自动归类。现在有这 5 类：`knife`(刀) / `revolver`+`gun`(左轮手枪) / `bat`(棒球棍) / `grenade`(手雷) / `hat`(帽子)。

要新增一个类型（比如 `xxx`），改 `src/main/java/org/agmas/noellesroles/client/screen/CS2WarehouseScreen.java` 里 4 处：

1. **枚举**加一项：
   ```java
   private enum Category { ALL, BOXES, KNIFE, REVOLVER, BAT, GRENADE, HAT, XXX, MUSIC, CARDS }
   ```

2. **`isSkinCategory`** 加上这个枚举值：
   ```java
   return c == Category.ALL || ... || c == Category.HAT || c == Category.XXX;
   ```

3. **`skinCategoryMatches`** 加一条映射：
   ```java
   case XXX -> "xxx".equals(itemType);
   ```

4. **两个侧边栏数组**（`renderSidebar` 和 `mouseClicked` 里各一处）补上分类和中文名：
   ```java
   Category[] categories = { ..., Category.HAT, Category.XXX, Category.MUSIC, Category.CARDS };
   String[] labels = { ..., "帽子", "XXX中文名", "音乐盒", "职业卡" };
   ```

> 注意：`skinId` 里 `类型` 那一段要和 `skinCategoryMatches` 里的字符串完全一致（区分大小写）。皮肤本身不用改，前缀对上了就会自动归到新分类。

## 六、把瑞科德饰品加进创造物品栏标签页

瑞科德饰品（帽子/钢盔）除了是 CS2 仓库皮肤，还要注册成一个**物品**，才能出现在创造物品栏的「瑞科德饰品」标签页里。

1. 在 `src/main/java/org/agmas/noellesroles/init/ModItems.java` 里注册物品，并把 `RICORD_ACCESSORIES_GROUP` 传进去：
   ```java
   public static final Item RICORD_GREEN_CAMO_HELMET = register(
           new Item(new Item.Properties().stacksTo(1)),
           "ricord_green_camo_helmet", RICORD_ACCESSORIES_GROUP);
   ```

2. 给这个物品建一个物品模型 `models/item/ricord_green_camo_helmet.json`，用 `parent` 指向 3D 帽子模型（这样创造栏图标显示的是 3D 钢盔，不是平贴图）：
   ```json
   {
       "parent": "starrailexpress:item/skins/hat/hat_ricord_green_camo",
       "display": {
           "gui": { "rotation": [30, 45, -60], "translation": [0, 0, 0], "scale": [0.55, 0.55, 0.55] }
       }
   }
   ```

> 标签页「瑞科德饰品」本身已在 `TMMItems` 里注册好（`RICORD_ACCESSORIES_GROUP`），图标用的是第一个饰品物品。以后新增饰品，物品直接传 `RICORD_ACCESSORIES_GROUP` 就会自动进这个标签页，不用再改标签页注册代码。
