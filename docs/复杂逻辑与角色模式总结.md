## 1. 角色组件模式

### 基础结构

所有角色组件必须实现 `RoleComponent` 接口，并根据需要实现 `ServerTickingComponent` 和/或 `ClientTickingComponent`：

```java
public class MyRolePlayerComponent implements RoleComponent, ServerTickingComponent, ClientTickingComponent {
    // 组件 Key（也可在 ModComponents 中直接定义）
    public static final ComponentKey<MyRolePlayerComponent> KEY = ComponentRegistry.getOrCreate(
        ResourceLocation.fromNamespaceAndPath(Noellesroles.MOD_ID, "my_role"),
        MyRolePlayerComponent.class);

    private final Player player;
    public int someState;

    public MyRolePlayerComponent(Player player) {
        this.player = player;
    }

    @Override
    public Player getPlayer() { return player; }

    @Override
    public boolean shouldSyncWith(ServerPlayer p) { return p == this.player; }

    public void sync() { KEY.sync(this.player); }

    // 游戏开始分配角色时调用（重置状态）
    @Override
    public void init() {
        this.someState = 0;
        sync();
    }

    // 游戏结束时调用（清理状态）
    @Override
    public void clear() { init(); }

    // 服务端每 tick
    @Override
    public void serverTick() { /* ... */ }

    // 客户端每 tick（仅当实现了 ClientTickingComponent）
    @Override
    public void clientTick() { /* ... */ }

    // 同步数据写入（服务端 → 客户端）
    @Override
    public void writeToSyncNbt(CompoundTag tag, HolderLookup.Provider lookup) {
        tag.putInt("someState", someState);
    }

    @Override
    public void readFromSyncNbt(CompoundTag tag, HolderLookup.Provider lookup) {
        someState = tag.getInt("someState");
    }

    // 持久化数据（通常留空，除非需要跨局保存）
    @Override
    public void writeToNbt(CompoundTag tag, HolderLookup.Provider lookup) {}

    @Override
    public void readFromNbt(CompoundTag tag, HolderLookup.Provider lookup) {}
}
```

### 在 ModComponents 注册

```java
public static final ComponentKey<MyRolePlayerComponent> MY_ROLE = ComponentRegistry.getOrCreate(
    ResourceLocation.fromNamespaceAndPath(Noellesroles.MOD_ID, "my_role"),
    MyRolePlayerComponent.class);

// 在 registerComponents() 中
registry.beginRegistration(Player.class, MY_ROLE)
    .respawnStrategy(RespawnCopyStrategy.NEVER_COPY)
    .end(MyRolePlayerComponent::new);
```

### 在 fabric.mod.json 注册

```json
"cardinal-components": [
  "noellesroles:my_role"
]
```

## 2. 技能系统详解

### RoleSkill.skill() Builder 完整用法

```java
// 在 ModRolesInitialEventRegister 中注册
RoleSkill.register(ModRoles.MY_ROLE,
    // 普通技能（按 G）
    RoleSkill.skill(SRE.id("my_role_ability"),
        "skill.noellesroles.my_role.ability",
        context -> {
            ServerPlayer player = context.player();
            UUID target = context.target();  // 可能为 null
            ResourceLocation skillId = context.skillId();
            RoleSkill.Phase phase = context.phase();
            boolean ready = context.skillReady();
            
            var comp = ModComponents.MY_ROLE.get(player);
            return comp.useSkill();  // 返回 true 进入冷却
        })
        .cooldownSeconds(30)      // 冷却 30 秒
        .charges(3)               // 最多使用 3 次（-1 无限）
        .announceToSelf(true)     // 向自己广播
        .toggleable(false)        // 不允许在冷却中触发
        .shifted(false)           // 不需要 Shift+G
        .showOnHud(true)          // 在 HUD 显示
        .build()
);
```

### 多技能注册（同一角色注册多个技能）

```java
RoleSkill.register(ModRoles.MY_ROLE,
    // 普通技能（按 G）
    RoleSkill.skill(SRE.id("my_role_ability"),
        "skill.noellesroles.my_role.ability",
        context -> {
            var comp = ModComponents.MY_ROLE.get(context.player());
            return comp.useAbility();
        }).build(),
    
    // Shift+G 技能（切换模式）
    RoleSkill.skill(SRE.id("my_role_toggle"),
        "skill.noellesroles.my_role.toggle",
        context -> {
            ModComponents.MY_ROLE.get(context.player()).toggleMode();
            return true;
        }).shifted(true).announceToSelf(false).showOnHud(false).build()
);
```

### 旧版兼容（不推荐）

```java
// 直接注册 Consumer（无冷却/次数管理）
RoleSkill.register(ModRoles.MY_ROLE, context -> {
    ServerPlayer player = context.player();
    // 技能逻辑...
});
```

## 3. 客户端临时方块机制

### 架构模式

参考 `ClientWallManager`（建筑师）和 `ClientFurnitureManager`（管家）：

```java
public class ClientXxxManager {
    private static final Map<UUID, BlockData> activeBlocks = new ConcurrentHashMap<>();

    // 放置方块（从 S2C 包调用）
    public static void placeBlock(UUID blockId, List<BlockPos> positions, int type, int durationTicks) {
        BlockData data = new BlockData(positions, type, durationTicks);
        activeBlocks.put(blockId, data);
        // 设置客户端方块
        for (BlockPos pos : positions) {
            ClientLevel level = Minecraft.getInstance().level;
            level.setBlock(pos, blockState, Block.UPDATE_CLIENTS);
        }
    }

    // 每 tick 调用
    public static void tick() {
        activeBlocks.values().removeIf(data -> {
            data.remainingTicks--;
            data.restoreIfNeeded();  // 恢复被破坏的方块
            if (data.remainingTicks <= 0) {
                data.remove();       // 移除方块
                return true;
            }
            if (data.remainingTicks < 100) {  // 最后 5 秒粒子提示
                data.spawnParticles();
            }
            return false;
        });
    }

    // 游戏结束清理
    public static void clearAll() {
        activeBlocks.values().forEach(BlockData::remove);
        activeBlocks.clear();
    }
}
```

### 注册点

```java
// NoellesrolesClient.onInitializeClient()
ClientPlayNetworking.registerGlobalReceiver(MyBlockS2CPacket.ID, (payload, context) -> {
    context.client().execute(() -> {
        ClientXxxManager.placeBlock(payload.blockId(), payload.positions(), ...);
    });
});

// 在 client tick 回调中
ClientTickEvents.END_CLIENT_TICK.register(client -> {
    if (client.level != null) {
        ClientXxxManager.tick();
    }
});

// 在游戏结束事件中
ClientXxxManager.clearAll();
```

## 5. 网络包完整流程

### 1. 定义包

```java
// C2S 包
public record MyAbilityC2SPacket(boolean shiftDown) implements CustomPacketPayload {
    public static final Type<MyAbilityC2SPacket> ID = new Type<>(
        ResourceLocation.fromNamespaceAndPath(Noellesroles.MOD_ID, "my_ability"));
    
    public static final StreamCodec<RegistryFriendlyByteBuf, MyAbilityC2SPacket> CODEC =
        CustomPacketPayload.codec(MyAbilityC2SPacket::write, MyAbilityC2SPacket::new);
    
    public MyAbilityC2SPacket(RegistryFriendlyByteBuf buf) {
        this(buf.readBoolean());
    }
    
    public void write(RegistryFriendlyByteBuf buf) {
        buf.writeBoolean(shiftDown);
    }
    
    @Override
    public Type<? extends CustomPacketPayload> type() { return ID; }
}

// S2C 包（携带更多数据）
public record MyBlockS2CPacket(UUID blockId, List<BlockPos> positions, int type, int durationTicks) 
    implements CustomPacketPayload {
    // 同上模式，注意 List<BlockPos> 的序列化
}
```

### 2. 注册包类型

在 `RicePacketTypeRegister.register()` 中：

```java
PayloadTypeRegistry.playC2S().register(MyAbilityC2SPacket.ID, MyAbilityC2SPacket.CODEC);
PayloadTypeRegistry.playS2C().register(MyBlockS2CPacket.ID, MyBlockS2CPacket.CODEC);
```

### 3. 服务端接收 C2S

在 `ModPacketsReciever` 中：

```java
ServerPlayNetworking.registerGlobalReceiver(MyAbilityC2SPacket.ID, (payload, context) -> {
    ServerPlayer player = context.player();
    context.server().execute(() -> {
        var comp = ModComponents.MY_ROLE.get(player);
        if (payload.shiftDown()) {
            comp.toggleMode();
        } else {
            comp.useAbility();
        }
    });
});
```

### 4. 客户端接收 S2C

在 `NoellesrolesClient` 中：

```java
ClientPlayNetworking.registerGlobalReceiver(MyBlockS2CPacket.ID, (payload, context) -> {
    context.client().execute(() -> {
        ClientXxxManager.placeBlock(payload.blockId(), payload.positions(), 
            payload.type(), payload.durationTicks());
    });
});
```

### 5. 发送包

```java
// 服务端发送 S2C 包
ServerPlayNetworking.send((ServerPlayer) player, new MyBlockS2CPacket(...));

// 客户端发送 C2S 包
ClientPlayNetworking.send(new MyAbilityC2SPacket(shiftDown));
```

## 6. HUD 渲染

### RoleHudRenderCallback（推荐）

```java
// 在 OtherRolesRegister 中调用 MyRoleHud.register()
public class MyRoleHud {
    public static void register() {
        RoleHudRenderCallback.EVENT.register(
            ModRoles.MY_ROLE_ID,
            (context, tickCounter) -> {
                Minecraft client = Minecraft.getInstance();
                Component text = Component.translatable("hud.noellesroles.my_role.status");
                int color = 0x55FF55;
                int screenWidth = context.guiWidth();
                int screenHeight = context.guiHeight();
                int textWidth = client.font.width(text);
                
                int x = screenWidth - textWidth - 10;
                int y = screenHeight - 20;
                context.drawString(client.font, text, x, y, color);
            }
        );
    }
}
```

**优点**：只在玩家是该职业时调用，无需手动判断。

## 7. 独立胜利条件

### 正确方式

```java
// 触发自定义胜利
RoleUtils.customWinnerWin(
    serverLevel,
    GameUtils.WinStatus.CUSTOM,
    ModRoles.MY_ROLE_ID.getPath(),  // 使用角色 ID 的 path
    OptionalInt.of(ModRoles.MY_ROLE.color())
);
```

**禁止**：
- ❌ 不要新增 `GameUtils.WinStatus` 枚举项
- ❌ 不要直接调用 `GameUtils.stopGame(...)`
- ❌ 不要使用玩家名或临时标签作为 `winnerId`

### AllowGameEnd 检查

```java
AllowGameEnd.EVENT.register((serverLevel, currentWinStatus, isLooseEndsMode) -> {
    if (myWinConditionMet()) {
        return GameUtils.WinStatus.CUSTOM;
    }
    return GameUtils.WinStatus.NOT_MODIFY;
});
```

## 9. 双格方块处理

### 床的特殊处理

```java
// 服务端：检查两个位置都为空气
BlockPos footPos = basePos;
BlockPos headPos = basePos.relative(facing);

if (!level.getBlockState(footPos).isAir() || !level.getBlockState(headPos).isAir()) {
    // 空间不足
    return false;
}

// 检查维度是否允许床
if (!level.dimensionType().bedWorks()) {
    // 地狱/末地不能使用床
    return false;
}

// 客户端：设置床的属性
ClientLevel clientLevel = Minecraft.getInstance().level;
BlockState bedState = Blocks.WHITE_BED.defaultBlockState()
    .setValue(BedBlock.FACING, facing)
    .setValue(BedBlock.OCCUPIED, false);

clientLevel.setBlock(footPos, bedState.setValue(BedBlock.PART, BedPart.FOOT), Block.UPDATE_CLIENTS);
clientLevel.setBlock(headPos, bedState.setValue(BedBlock.PART, BedPart.HEAD), Block.UPDATE_CLIENTS);
```

### 方向索引转换

```java
// Direction → 索引（用于网络包传输）
public static int facingToIndex(Direction facing) {
    return switch (facing) {
        case NORTH -> 0;
        case SOUTH -> 1;
        case WEST -> 2;
        case EAST -> 3;
        default -> 0;
    };
}

// 索引 → Direction
public static Direction indexToFacing(int index) {
    return switch (index) {
        case 0 -> Direction.NORTH;
        case 1 -> Direction.SOUTH;
        case 2 -> Direction.WEST;
        case 3 -> Direction.EAST;
        default -> Direction.NORTH;
    };
}
```

## 10. 地面检测与空中限制

### player.onGround() 用法

```java
// 检查玩家是否在地面（包括跳跃滞空时返回 false）
if (!player.onGround()) {
    if (player instanceof ServerPlayer serverPlayer) {
        serverPlayer.displayClientMessage(
            Component.translatable("hud.noellesroles.my_role.in_air")
                .withStyle(ChatFormatting.RED),
            true);
    }
    return false;  // 技能失败
}
```

**注意**：`onGround()` 在跳跃滞空时也返回 `false`，因此可以有效防止空中使用技能。

## 附录：常见陷阱

1. **金币访问**：使用 `shop.balance` 而非 `shop.getBalance()`（后者不存在）
2. **组件同步**：修改组件状态后务必调用 `sync()` 方法
3. **客户端类引用**：服务端代码不要引用 `Minecraft.getInstance()` 等客户端类
4. **包注册顺序**：先注册包类型（`PayloadTypeRegistry`），再注册接收器（`registerGlobalReceiver`）
5. **fabric.mod.json**：新增 CCA 组件必须在 `cardinal-components` 数组中注册，否则崩溃
6. **双格方块**：床需要检查两个位置都为空气，并处理 `BedBlock.PART` 属性
7. **维度检查**：床在下界/末地会爆炸，使用 `dimensionType().bedWorks()` 检查
