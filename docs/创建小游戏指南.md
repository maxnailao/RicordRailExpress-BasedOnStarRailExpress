## 1. 框架概览

```
┌─────────────────────────────────────────────┐
│  GameConsoleItem (右键打开掌机)              │
│    └─ GameConsoleScreen (游戏选择界面)       │
│         └─ GameConsoleGames.getAvailable()   │
│              └─ QuestMinigames (注册表)       │
│                   └─ MinigameScreenFactory   │
│                        └─ YourMinigameScreen │
└─────────────────────────────────────────────┘
```

**核心文件一览：**

| 文件 | 作用 |
|------|------|
| `QuestMinigames.java` | 全局注册表，声明小游戏枚举 |
| `MinigameScreenFactory.java` | 客户端工厂，ID → Screen 实例 |
| `GameConsoleGames.java` | 掌机白名单 + 积分榜开关 |
| `ModPackets.java` | 服务端网络包注册 |
| `SREClient.java` | 客户端 S2C 接收器注册 |
| `ModEventsRegister.java` | Tick 事件注册（AI/超时驱动） |

## 3. 第一步：注册小游戏 ID

在 `QuestMinigames.java` 中添加枚举：

```java
/** 你的小游戏 */
public static final QuestMinigame YOUR_GAME = register(
    QuestMinigame.of("your_game", "minigame.starrailexpress.your_game"));
```

- **ID**：全局唯一标识，如 `"mahjong"`, `"doudizhu"`
- **翻译键**：用于游戏选择界面的显示名称

## 4. 第二步：客户端 Screen

### 4.1 创建 Screen 类

继承 `Screen`，实现 `render()` 和交互方法：

```java
public class YourMinigameScreen extends Screen {

    private final Runnable onSuccess;

    public YourMinigameScreen(BlockPos pos, Runnable onSuccess) {
        super(Component.literal("你的游戏"));
        this.onSuccess = onSuccess;
    }

    @Override
    protected void init() {
        super.init();
        // 发送加入游戏的 C2S 包
        ClientPlayNetworking.send(new YourJoinC2SPacket(...));
        // 添加"离开"按钮
    }

    @Override
    public void render(GuiGraphics g, int mx, int my, float pt) {
        renderBackground(g, mx, my, pt);
        // 绘制游戏界面
        super.render(g, mx, my, pt);
    }

    // 接收服务端状态更新
    public void onStateReceived(YourStateS2CPacket pkt) {
        // 更新本地状态，触发重绘
    }

    @Override
    public boolean isPauseScreen() { return false; }
}
```

### 4.2 注册工厂

在 `MinigameScreenFactory.java` 的 static 块中添加：

```java
FACTORY.put("your_game", YourMinigameScreen::new);
```

### 4.3 UI 绘制建议

推荐纯代码绘制（`g.fill()` + `g.drawString()`），避免依赖贴图资源：

- **`g.fill(x1, y1, x2, y2, color)`**：填充矩形（颜色含 alpha：`0xAARRGGBB`）
- **`g.drawString(font, text, x, y, color, shadow)`**：绘制文字
- **`g.blit(...)`**：贴图绘制（需要提供 `Identifier` 和 UV 坐标）

颜色常量推荐集中定义：
```java
private static final int C_BG = 0xFF1B5E20;      // 背景
private static final int C_BORDER = 0xFF5D4037;   // 边框
private static final int C_TEXT = 0xFFFFFFFF;      // 文字
```

## 5. 第三步：网络包设计

### 5.1 包类型规范

每个联网小游戏通常需要：

| 方向 | 包名 | 作用 |
|------|------|------|
| C2S | `YourJoinC2SPacket` | 加入/离开游戏 |
| C2S | `YourActionC2SPacket` | 玩家操作（出牌/落子等） |
| S2C | `YourStateS2CPacket` | 服务端→客户端状态同步 |

### 5.2 C2S 包模板

```java
public record YourJoinC2SPacket(byte action) implements CustomPacketPayload {

    public static final byte ACTION_JOIN = 1;
    public static final byte ACTION_LEAVE = 0;

    public static final Type<YourJoinC2SPacket> TYPE =
        new Type<>(new ResourceLocation("starrailexpress", "your_join"));

    public static final StreamCodec<RegistryFriendlyByteBuf, YourJoinC2SPacket> CODEC =
        StreamCodec.composite(
            ByteBufCodecs.BYTE, YourJoinC2SPacket::action,
            YourJoinC2SPacket::new
        );

    @Override
    public Type<? extends CustomPacketPayload> type() { return TYPE; }

    // 服务端处理
    public void handle(ServerPlayer player) {
        if (action == ACTION_JOIN) {
            YourSessionManager.INSTANCE.handleJoin(player);
        } else {
            YourSessionManager.INSTANCE.handleLeave(player);
        }
    }
}
```

### 5.3 S2C 状态包模板

```java
public record YourStateS2CPacket(
    byte phase,
    byte playerIndex,
    byte[] myData,
    String[] names
    // ... 根据游戏需要添加字段
) implements CustomPacketPayload {

    public static final Type<YourStateS2CPacket> TYPE =
        new Type<>(new ResourceLocation("starrailexpress", "your_state"));

    public static final StreamCodec<RegistryFriendlyByteBuf, YourStateS2CPacket> CODEC =
        StreamCodec.of(YourStateS2CPacket::encode, YourStateS2CPacket::decode);

    private void encode(RegistryFriendlyByteBuf buf) {
        buf.writeByte(phase);
        buf.writeByte(playerIndex);
        // 手动序列化（FriendlyByteBuf 无 writeIntArray）
        buf.writeByte(myData.length);
        for (byte b : myData) buf.writeByte(b);
        for (int i = 0; i < 4; i++) buf.writeUtf(names[i]);
    }

    private static YourStateS2CPacket decode(RegistryFriendlyByteBuf buf) {
        byte phase = buf.readByte();
        byte playerIndex = buf.readByte();
        int len = buf.readByte();
        byte[] data = new byte[len];
        for (int i = 0; i < len; i++) data[i] = buf.readByte();
        String[] names = new String[4];
        for (int i = 0; i < 4; i++) names[i] = buf.readUtf();
        return new YourStateS2CPacket(phase, playerIndex, data, names);
    }

    @Override
    public Type<? extends CustomPacketPayload> type() { return TYPE; }
}
```

### 5.4 注册网络包

**服务端** `ModPackets.java`：
```java
// C2S
PayloadTypeRegistry.playC2S().register(YourJoinC2SPacket.TYPE, YourJoinC2SPacket.CODEC);
PayloadTypeRegistry.playC2S().register(YourActionC2SPacket.TYPE, YourActionC2SPacket.CODEC);
// S2C
PayloadTypeRegistry.playS2C().register(YourStateS2CPacket.TYPE, YourStateS2CPacket.CODEC);
// 服务端接收器
ServerPlayNetworking.registerGlobalReceiver(YourJoinC2SPacket.TYPE, YourJoinC2SPacket::handle);
ServerPlayNetworking.registerGlobalReceiver(YourActionC2SPacket.TYPE, YourActionC2SPacket::handle);
```

**客户端** `SREClient.java`：
```java
ClientPlayNetworking.registerGlobalReceiver(
    YourStateS2CPacket.TYPE,
    (payload, context) -> context.client().execute(() -> {
        if (context.client().screen instanceof YourMinigameScreen screen) {
            screen.onStateReceived(payload);
        }
    }));
```

## 6. 第四步：服务端逻辑

### 6.1 架构模式（推荐）

```
SessionManager (单例)
  ├─ waitingQueue: 等待队列
  ├─ activeGames: Map<UUID, Session>
  └─ handleJoin/Leave/Action → 路由到 Session

Session (每局一个)
  ├─ players[]: ServerPlayer[]
  ├─ 游戏状态（手牌/棋盘/分数等）
  ├─ broadcastState(): 为每个玩家发送个性化 S2C
  └─ handleXxx(): 各种操作处理
```

### 6.2 SessionManager 模板

```java
public class YourSessionManager {
    public static final YourSessionManager INSTANCE = new YourSessionManager();

    private final List<ServerPlayer> waitingQueue = new ArrayList<>();
    private final Map<UUID, YourSession> activeGames = new HashMap<>();

    public void handleJoin(ServerPlayer player) {
        UUID uuid = player.getUUID();
        if (activeGames.containsKey(uuid)) return;
        waitingQueue.add(player);

        if (waitingQueue.size() >= REQUIRED_PLAYERS) {
            // 凑够人数，开始游戏
            ServerPlayer[] players = new ServerPlayer[REQUIRED_PLAYERS];
            for (int i = 0; i < REQUIRED_PLAYERS; i++)
                players[i] = waitingQueue.remove(0);
            startGame(players);
        } else {
            // 发送等待状态
            sendWaitingState(player);
        }
    }

    private void startGame(ServerPlayer... players) {
        YourSession session = new YourSession(players);
        for (ServerPlayer p : players)
            activeGames.put(p.getUUID(), session);
        session.broadcastState();
    }

    public void tick() {
        // 每tick调用，处理超时等
        for (YourSession s : activeGames.values()) s.tickTimeout();
    }
}
```

### 6.3 服务端权威原则

- **所有游戏逻辑在服务端执行**，客户端只负责渲染和发送操作请求
- 客户端收到 S2C 状态包后更新本地状态并重绘
- 不要信任客户端发来的数据，务必在服务端验证

### 6.4 broadcastState 要点

```java
public void broadcastState() {
    for (int i = 0; i < playerCount; i++) {
        ServerPlayer p = players[i];
        if (p == null) continue;
        // 为每个玩家构建个性化状态包
        // （例如：自己的手牌完整发送，对手只发数量）
        YourStateS2CPacket pkt = buildStateFor(i);
        ServerPlayNetworking.send(p, pkt);
    }
}
```

## 7. 第五步：Tick 驱动（可选）

如果你的游戏需要定时驱动（AI 思考、动作超时等），在 `ModEventsRegister.java` 中注册：

```java
ServerTickEvents.END_SERVER_TICK.register(server -> {
    YourSessionManager.INSTANCE.tick();
});
```

**注意**：tick 方法要轻量，避免每 tick 都执行重计算。

## 9. 网络包模板参考

### 关键注意事项

1. **`FriendlyByteBuf` 没有 `writeIntArray`**：数组需要手动逐字节/逐int 序列化
2. **byte 与 int 转换**：发送 byte 后客户端读取时用 `& 0xFF` 转回无符号 int
3. **record 类型**：推荐用 Java record 实现 `CustomPacketPayload`
4. **ResourceLocation**：统一用 `"starrailexpress"` 命名空间

### 数据结构编码示例

```java
// 变长 byte 数组
buf.writeByte(arr.length);
for (byte b : arr) buf.writeByte(b);

// 字符串数组
buf.writeByte(names.length);
for (String s : names) buf.writeUtf(s);

// 二维 byte 数组
buf.writeByte(arrays.length);
for (byte[] a : arrays) {
    buf.writeByte(a.length);
    for (byte b : a) buf.writeByte(b);
}
```

## 11. 常见问题与踩坑

### Q1: 如何给小游戏加积分榜？

```java
// GameConsoleGames.java 的 static 块
SCOREBOARD_ENABLED_IDS.add("your_game");
```

单机游戏（如打靶、俄罗斯方块）通过 `ScoreboardSubmitC2SPacket` 提交分数。

### Q2: 纯单机游戏需要 Session 吗？

不需要。单机游戏（如 `target_shooting`, `tetris`）只需 Screen 类，不需要 SessionManager/Session 和网络包。

### Q3: 客户端 S2C 包接收不到？

检查：
- `SREClient.java` 中是否注册了 receiver
- receiver 是否用 `context.client().execute()` 切到主线程
- Screen 类型判断是否正确（`instanceof`）

### Q4: 多人游戏对手数据显示相同？

**关键**：`buildStateFor(playerIdx)` 必须为每个玩家生成**个性化**的数据包。如果 `allDiscards` / `oppCounts` 等使用绝对索引，客户端必须做**相对座位映射**：

```java
// 客户端：将相对索引转为绝对座位号
int oppSeat = (playerIndex + 2) % 4;  // 对家
int rightSeat = (playerIndex + 1) % 4; // 右邻
int leftSeat = (playerIndex + 3) % 4;  // 左邻
```

### Q5: 碰/吃等操作卡顿？

确保**无可用动作的玩家**自动标记为已响应，否则服务器会等待15秒超时：

```java
// 在 checkActions 中
for (int i = 0; i < 4; i++) {
    if (availableActions[i][0] == ACTION_NONE) {
        hasResponded[i] = true;
        chosenActions[i] = ACTION_PASS;
    }
}
```

### Q6: UI 贴图还是纯代码绘制？

**推荐纯代码绘制**：
- 避免资源加载失败导致的黑屏
- 更容易调试和修改
- `g.fill()` 画矩形 + `g.drawString()` 写文字即可覆盖大部分需求
- 颜色用 `0xAARRGGBB` 格式，注意 alpha 通道

### Q7: 如何添加 AI 补位？

参考 `DoudizhuSession`：
1. 检测玩家不足时创建虚拟 `ServerPlayer`（或用 null 占位）
2. 在 tick 中驱动 AI 决策
3. AI 决策应加随机延迟（500-2000ms）避免瞬发
