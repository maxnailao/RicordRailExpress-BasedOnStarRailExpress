## Project Origin Declaration

This project (RicordRailExpress) is a secondary modification based on the **StarRail Express** mod, which was developed and extended by the **CanYue Team (残月团队)**. It is produced by the **Ricord Rail Express Production Team (瑞科德列车制作组)**.

The source code used in this project originates from the publicly released open-source code of StarRail Express by the CanYue Team. We have further developed, modified, and optimized it to suit the needs and design philosophy of the Ricord Rail Express Production Team.

## Acknowledgements

We hereby express our sincere gratitude to the **CanYue Team**. We thank them for releasing StarRail Express in open-source form, enabling us to build upon and improve their excellent work. Without the CanYue Team's open-source spirit and dedicated efforts, this project would not have been possible.
